# OrangeEventra 🍊

OrangeEventra is a MERN-based event booking platform that allows users to explore events, book tickets, and enables admins to manage events, availability, and pricing.

---

## 🚀 Features
- Browse events like concerts, movies, sports, and comedy shows
- Step-by-step ticket booking flow (date, seats, confirmation)
- QR code generation for ticket verification
- Admin dashboard for event and booking management
- Responsive UI
- Authentication-ready structure
- Real-world inspired (Eventbrite, Ticketmaster)

## 🛠 Tech Stack
**Frontend**
- React.js
- React Router
- CSS / Inline Styling

**Backend**
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication (planned)

All the codes and folders are uploaded in the respective directories
